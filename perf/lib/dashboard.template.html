What is covered

    How to read this

    • Every interaction counts the same, whatever its traffic.
    • This is a lab, not real visitors: runs compare with each other and do not predict production numbers.
    • The database round trip is an assumed ms. Serverless cold starts and Vercel's edge cache are not modelled.
    • Some writes run on small throwaway loops, so they understate the cost on a large loop.
